# 上班偷看盤:安裝說明

全部免費,不用註冊、不用付款。第一次大約需要 1 小時,大部分時間是等電腦下載。

你需要準備:
- Windows 電腦一台
- 手機(Galaxy S24 Ultra)的 USB 傳輸線
- 手機、手錶、電腦連在**同一個 Wi-Fi**

---

## 第 1 步:在電腦安裝 Android Studio(免費)

1. 用電腦打開 https://developer.android.com/studio
2. 按綠色的「Download Android Studio」,勾選同意,下載。
3. 打開下載好的檔案,一路按「Next」,最後按「Install」,再按「Finish」。
4. 第一次打開時會跳出設定畫面:選「Standard」→ 一路按「Next」→ 遇到授權畫面就選「Accept」→「Finish」。
5. 接著它會自己下載很多東西,等到畫面出現「Finish」就按下去。

## 第 2 步:打開這個專案

1. 把我給你的 `stock-watch.zip` 解壓縮,例如放到 `C:\stock-watch`。
2. 在 Android Studio 按「Open」,選 `stock-watch` 這個資料夾,按「OK」。
3. 如果問你「Trust Project?」,按「Trust Project」。
4. 等畫面最下方的進度條跑完(第一次可能 5–15 分鐘)。
5. 如果右下角跳出「建議升級」之類的提示,**直接關掉就好**,不要按升級。

## 第 3 步:打開手機的「開發者模式」

1. 手機打開「設定」→「關於手機」→「軟體資訊」。
2. 連續點「版本號碼」7 下,輸入手機解鎖密碼,會看到「開發人員模式已開啟」。
3. 回到「設定」最下面,會多一個「開發人員選項」,點進去,打開「USB 偵錯」。
4. 用 USB 線把手機接到電腦,手機跳出「允許 USB 偵錯?」時,勾「一律允許」再按「允許」。

## 第 4 步:把 App 放進手機

1. Android Studio 上方工具列,左邊的下拉選單選「**mobile**」。
2. 旁邊的裝置選單選你的手機(名稱類似 Samsung SM-S928…)。
3. 按綠色的 ▶(Run)。
4. 等一下,手機上就會打開「上班偷看盤」。

## 第 5 步:打開手錶的「開發者模式」

1. 手錶打開「設定」→「關於手錶」→「軟體」(或「軟體資訊」)。
2. 連續點「軟體版本」大約 7 下,直到出現「開發人員模式已開啟」。
3. 回到「設定」,點「開發人員選項」:
   - 打開「ADB 偵錯」
   - 打開「透過 Wi-Fi 偵錯」(無線偵錯)
4. 手錶「設定」→「連接」→「Wi-Fi」,確認連上**和電腦同一個 Wi-Fi**。
5. 回到「開發人員選項」→「無線偵錯」→「配對新裝置」,手錶會顯示一組 **6 位數字**,畫面先不要關。

## 第 6 步:把 App 放進手錶

1. Android Studio 上方裝置選單 → 選「Pair Devices Using Wi-Fi」。
2. 點上面的「Pair using pairing code」分頁,等你的手錶出現在清單,按「Pair」。
3. 輸入手錶上顯示的 6 位數字,按「Pair」。
4. 左邊的下拉選單改選「**wear**」,裝置選單選你的手錶。
5. 按綠色的 ▶。等一下,手錶上就會打開「上班偷看盤」。
6. 裝好之後,可以回手錶把「透過 Wi-Fi 偵錯」關掉,比較省電。

> 重要:手機版和手錶版**一定要從同一台電腦安裝**,兩邊才能互相傳清單。

## 第 7 步:逐項測試

請照順序試,哪一項不對就截圖或用文字告訴我是第幾項、看到什麼。

| # | 怎麼試 | 應該看到 |
|---|---|---|
| 1 | 打開手機 App | 清單有:加權指數、台積電、元大台灣50 |
| 2 | 輸入 `2317` 按新增 | 清單多一列「鴻海」 |
| 2 | 輸入 `9999999` 按新增 | 提示「找不到這檔股票」 |
| 3 | 輸入「台積」 | 下面列出台積電,點它就加入 |
| 3 | 輸入「元大」 | 列出一串元大的 ETF |
| 4 | 把鴻海按「刪除」,關掉 App 再打開 | 鴻海還是不在 |
| 5 | 把 0050 按 ▲ 移到第一個 | 手錶上也變第一個 |
| 6 | 新增一檔股票 | 手機顯示「已同步到手錶」,手錶 10 秒內出現 |
| 6 | 手錶藍牙關掉再新增一檔 | 手機顯示「手錶未連線,稍後會自動補傳」;重新連線後手錶自動出現 |
| 7 | 手錶看清單,轉錶圈或手指滑 | 名稱、現價、漲跌、百分比;紅漲綠跌白平盤,和券商 App 一致 |
| 8 | 開盤時看清單 | 價格自己跳動;放下手腕再抬起來是最新價格 |
| 8 | 收盤後打開 | 下方寫「非交易時間・收盤價」 |
| 9 | 點一檔股票 | 看到開盤、最高、最低、昨收、成交量與走勢圖 |
| 10 | 關掉手錶網路再打開詳細頁 | 顯示「無法取得資料」,不會當機 |
| 11 | 手錶 Wi-Fi 與手機連線都關掉後打開 App | 顯示「連不上網路」;恢復後自動更新 |
| 12 | 手機關機,手錶連 Wi-Fi | 手錶仍能看清單與價格 |

在手錶上:往右滑可以從詳細頁回到清單。
